# Keyboard Shortcuts

ApiBolt provides extensive keyboard shortcuts to help you navigate and work more efficiently. Below is a complete reference of all **default** keyboard shortcuts organized by category.

> **Note:** The modifier keys follow this order: `Ctrl` → `Shift` → `Alt` → `Meta` (Cmd on macOS)

## Navigation

Quickly jump to different sections of the application.

| Shortcut               | Action                        |
| ---------------------- | ----------------------------- |
| `Ctrl` + `Shift` + `P` | Navigate to projects          |
| `Ctrl` + `Shift` + `C` | Navigate to collections       |
| `Ctrl` + `Shift` + `E` | Navigate to environments      |
| `Ctrl` + `Shift` + `A` | Navigate to authorization     |
| `Ctrl` + `Shift` + `S` | Navigate to mock server       |
| `Ctrl` + `Shift` + `M` | Navigate to theme marketplace |
| `Ctrl` + `Shift` + `T` | Navigate to theme editor      |

## UI Toggles

Show or hide various interface elements.

| Shortcut         | Action                |
| ---------------- | --------------------- |
| `Meta` + `A`     | Toggle activitybar    |
| `Ctrl` + `B`     | Toggle sidebar        |
| `F11`            | Toggle fullscreen     |
| `Ctrl` + `` ` `` | Toggle response panel |

## Application

Access application settings and information.

| Shortcut             | Action                 |
| -------------------- | ---------------------- |
| `Ctrl` + `Alt` + `I` | Open App Info          |
| `Ctrl` + `Alt` + `C` | Open Cookies           |
| `Ctrl` + `Alt` + `K` | Open keyboard shortcut |
| `Ctrl` + `,`         | Open Settings          |
| `Ctrl` + `Alt` + `P` | Open Local Password    |

## Tabs

### Opening Tabs

| Shortcut               | Action         |
| ---------------------- | -------------- |
| `Ctrl` + `T`           | Open Tab       |
| `Ctrl` + `Shift` + `L` | Open Left Tab  |
| `Ctrl` + `Shift` + `R` | Open Right Tab |

### Closing Tabs

| Shortcut             | Action            |
| -------------------- | ----------------- |
| `Ctrl` + `F4`        | Close Current Tab |
| `Ctrl` + `Alt` + `A` | Close All Tabs    |
| `Ctrl` + `Alt` + `O` | Close Others Tabs |
| `Ctrl` + `Alt` + `L` | Close Left Tabs   |
| `Ctrl` + `Alt` + `E` | Close Right Tabs  |

### Switching & Locking Tabs

| Shortcut                 | Action                |
| ------------------------ | --------------------- |
| `Ctrl` + `Shift` + `Tab` | Switch to left tab    |
| `Ctrl` + `Tab`           | Switch to right tab   |
| `Ctrl` + `Meta` + `L`    | Lock/unlock tabs list |

## Search & Code

Quick search and code editing shortcuts.

| Shortcut              | Action            |
| --------------------- | ----------------- |
| `Ctrl` + `K`          | Search collection |
| `Alt` + `Z`           | Code line wrap    |
| `Shift` + `Alt` + `F` | Code beautify     |

## Zoom

Adjust zoom levels for the application and code editor.

### Application Zoom

| Shortcut     | Action     |
| ------------ | ---------- |
| `Ctrl` + `+` | Zoom in    |
| `Ctrl` + `-` | Zoom out   |
| `Ctrl` + `0` | Zoom reset |

### Code Editor Zoom

| Shortcut     | Action          |
| ------------ | --------------- |
| `Ctrl` + `+` | Code zoom in    |
| `Ctrl` + `-` | Code zoom out   |
| `Ctrl` + `0` | Code zoom reset |

## Tips

- These are the **default** keyboard shortcuts that come pre-configured with ApiBolt
- On macOS, `Meta` refers to the `Cmd` key
- You can view all keyboard shortcuts anytime by pressing `Ctrl` + `Alt` + `K`
- Some shortcuts may vary depending on your operating system and keyboard layout
- Custom shortcuts can be configured in Settings if needed
